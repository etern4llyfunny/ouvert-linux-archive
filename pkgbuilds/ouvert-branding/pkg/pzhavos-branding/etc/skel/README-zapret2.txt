║   Обход блокировок в PzhavOS — zapret2                        ║
╚══════════════════════════════════════════════════════════════╝

Если какие-то сайты или сервисы не открываются (YouTube, Discord
в браузере и т.п.) — в системе уже стоит zapret2. По умолчанию он
ВЫКЛЮЧЕН, чтобы не мешать. Включить нужно один раз, вручную.

──────────────────────────────────────────────────────────────
ШАГ 1. Подобрать рабочую стратегию

Открой терминал и выполни:

    sudo blockcheck2.sh

Скрипт проверит разные способы обхода и подскажет, какой из них
работает у твоего провайдера. Просто дождись конца проверки и
запомни (или скопируй) рекомендованную стратегию.

──────────────────────────────────────────────────────────────
ШАГ 2. Установить и включить

    sudo install_easy.sh

Отвечай на вопросы установщика по итогам первого шага. После
этого zapret2 запустится и будет работать сам при каждом
включении компьютера.

──────────────────────────────────────────────────────────────
Не нашлись команды?

Скрипты лежат вместе с zapret2. Найти их можно так:

    which blockcheck2.sh install_easy.sh

или заглянуть в папку установки zapret2.

──────────────────────────────────────────────────────────────
Полностью выключить обратно:

    sudo install_easy.sh   (в меню выбрать удаление службы)

Этот файл можно удалить — он ни на что не влияет.
