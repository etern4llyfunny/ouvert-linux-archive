## Блокеры

### B1. Обновления своих пакетов
Сейчас: config_gen.py вырезает [ouvert] из pacman.conf цели (стр. 268–280) —
намеренно, чтобы paru обновлял AUR-пересборки из AUR.
Замер t47/beta-18 (05.11): `pacman -Qm` → linux-ouvert 7.2.8-1 и
ouvert-branding 1.0-7 — сироты: ни в одном репо, ни в AUR, обновлений нет никогда.
Риск: paru ищет сирот в AUR по имени. Пакет `linux-ouvert` или `ouvert-branding`,
залитый в AUR кем угодно с версией выше, приедет на все установки при `paru -Syu`.
Направление: онлайн-репо [ouvert] только со СВОИМИ пакетами (linux-ouvert*,
ouvert-branding, ouvert-keyring), остаётся в pacman.conf цели. AUR-пересборки
(waterfox-bin, paru, protonup-qt, python-steam, python-inputs,
python-gevent-eventemitter) — только в локальном репо ISO, как сейчас.
Критерий: на свежей установке `pacman -Qm` не содержит linux-ouvert* и
ouvert-branding; выложенный ouvert-branding с pkgrel+1 приезжает через
`sudo pacman -Syu`.

### B2. Подпись репозитория
Сейчас: SigLevel = Optional TrustAll.
Критерий: [ouvert] с SigLevel = Required; ключ — пакет ouvert-keyring,
ставится установщиком; `pacman -Syu` проходит; пакет с битой подписью
pacman отвергает.

### B3. Обновление ядра linux-ouvert
Сейчас: 7.2.8, не обновлялось с конца сентября.
Критерий: записанная процедура (скрипт): сборка новой версии → подпись →
выкладка в репо; установленная ВМ обновилась через `pacman -Syu` и
загрузилась на новом ядре (`uname -r`).

### B4. Установка на реальном железе
Критерий: полная установка + загрузка + вход в окружение минимум на 3 машинах:
Intel или AMD графика, Nvidia, ноутбук (Wi-Fi, тачпад).
По каждой — строка: машина, окружение, бета, итог.

### B5. BIOS / legacy-загрузка — ЗАКРЫТ 09.11.2026
Закрыт: beta-19, ВМ t50 (SeaBIOS, virt-install без --boot uefi, в XML нет loader):
live через syslinux, установщик «BIOS (Legacy)», i3 без ошибок, GRUB с диска,
установленная: /sys/firmware/efi нет, vda PTTYPE dos, vda1 vfat /boot, vda2 btrfs.
Критерий: ВМ с SeaBIOS — live грузится, установка проходит, установленная
система грузится. Либо решение «только UEFI»: тогда live и установщик
внятно говорят об этом на BIOS-машине.

### B6. Bug 34(д) — повтор после оборванной установки
Сейчас: не замерен.
Критерий: обрыв на pacstrap → повторная установка на тот же диск проходит
без «Удалять нельзя: примонтирован» (после перезагрузки и, если такой путь
есть, без неё).

### B7. Bug 57 — два монитора
Сейчас: проверен только шаг 1 (окно целиком на одном мониторе).
Критерий: live на машине с двумя мониторами, все 11 шагов: окно видно
целиком, не растянуто, кнопки доступны.
